# 移動壁のバグ修正とエネルギー収支試験のまとめ（2026-10-19）

## 1. 概要

- **何をしたか：** 壁との仕事・熱のやり取りと数値加熱を確かめるため、エネルギー収支の試験を 2 つ追加した。
- **見つかったこと：** 気体衝突を有効にした長時間の試験（試験 B）で、`wallvel yes` のときに計算が停止するバグが見つかった。
- **対応：** `src/update.cpp` を修正した。修正後は、すべての試験に合格している。

## 2. バグ

### 症状
`wallvel yes` で気体衝突を有効にすると、1〜2 万ステップ目で次のエラーにより停止する。

```
ERROR: Collision cell volume is zero (collide.cpp)
```

### 原因
- 粒子が移動している間、壁は直前の位置で凍結している。
- 後退する壁で壁静止系の反射をすると、反射後の実験室系の速度が凍結した壁の裏を向く（v'·n < 0）ことがある。後退壁の古い位置を素通りする場合（wallframe = 2）は、必ずこうなる。
- その粒子は、凍結した壁の裏（固体側）へそのまま進む。
- ステップ末の退避（`engulf project`）で戻されるが、それより前に気体衝突の計算が行われる。
- そのとき、固体側のセル（体積 0）に粒子が 2 個以上いると停止する。

デバッグ版で数えた結果（8,000 ステップ）：固体側のセルで移動を終えた粒子は 61 件。内訳は、反射後に壁の裏を向いたもの 57 件、素通り 4 件、それ以外 0 件。

気体衝突のない試験では、ステップ末に戻されるので表に出ていなかった。

### 修正（`src/update.cpp`、`Update::move()`）
- 上の条件の粒子は、そのステップの残りの時間、衝突点に止める。
- 置く位置は、衝突点から気体側へ、セル寸法×10⁻⁶ ずらした点にする。
  - 衝突点ちょうどに置くと、次のステップで壁が動かない場合（nevery > 1）、「面の上から内側へ」と判定されて壁を素通りしてしまうため。
- 速度は変えないので、エネルギーと表面の集計は変わらない。
- 壁が後退すれば、粒子は気体側に残る。
- 誤差は、粒子の位置が最大 1 ステップ分遅れること。
- 止めた件数は、run の終わりに `Wall-frame stops = N` として表示する（`src/finish.cpp`、`src/update.h`）。
- `wallvel no` と `engulf delete` の動作は変わらない。

## 3. 追加した試験

| 試験 | 内容 | 判定 |
|---|---|---|
| A：`in.micro_energy`（`run_all.sh` に含む） | 冷たいビームを移動ピストン（拡散反射、100 m/s）に当てる。気体衝突なし | 衝突 1 回あたりの運動量 Fx、仕事 W = U·Fx、熱 Q = E − W、エネルギー E が、散乱核の理論値と一致すること |
| B：`in.macro_heating`（`run_macro_heating.sh` で別に実行） | 回転する正方形容器。気体衝突あり（Kn ≈ 0.2）、気体 100 K・壁 300 K から 5 万ステップ | 第一法則、温度の平均と傾き、定常の W・Q、剛体回転 |
| 後退ピストン（`in.piston -var dx -0.8`、`run_all.sh` に追加） | 鏡面ピストンが 100 m/s で後退する | 面圧が自由分子流の解析解と ±3% 以内で一致すること |

- 仕事と熱は `compute surf` の集計から求める。etot（エネルギー）は `norm flow` で出力する。
  - 仕事：並進は W = u_w·F、回転は ω·T（T はトルク）
  - 熱：Q = E − W
- 依頼文では dump で衝突前後の速度を出す想定だったが、dump では衝突の瞬間を取れない。そのため、衝突ごとに集計する `compute surf` を使った。

## 5. 付随して分かったこと

- **定常で残る仕事：** 試験 B では、定常でも小さな仕事 W ≈ −0.019 W が残る（nearcp no の場合）。
  - 原因は DSMC のペア衝突。2 粒子の位置が離れているぶん、衝突のたびに角運動量がわずかに保存されず、剛体回転では抵抗として働く。
  - 見積もり −2.7×10⁻⁴ N·m に対し、実測 −2.9×10⁻⁴ N·m で一致した。nearcp yes にすると約 1/4 に減る。
- **退避の寄与：** 気体衝突なしで測ると −1.7×10⁻⁵ N·m で、統計的に 0 と区別できない。めり込み補正の退避が人工的な摩擦を生んでいる証拠はない。
- **定常の W = Q = 0 の判定の限界：** 閉じた系の定常状態では、どんな方式でも E = W + Q は平均 0 になる。方式の違いを見分けられるのは、剛体回転のほうである。
